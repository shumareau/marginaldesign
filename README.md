# Marginal Design

Откройте index.html в браузере. Редактор остаётся одним HTML-файлом, его можно загрузить на GitHub Pages.

Плюс под последней полосой добавляет новую. Её ширина берётся с первой полосы на момент добавления, высота — 675 px. Каждая полоса редактируется отдельно.
Сохранение проекта включает все полосы. Старые однополосные проекты поддерживаются.
Экспорт HTML объединяет полосы вертикально без промежутков, сохраняя пропорциональное масштабирование под экран.

Для отката замените index.html копией backups/before-multiple-artboards.html.
